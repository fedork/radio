# Cold Sa(193) run comparison, finalized 2026-08-16

Purpose
-------

Classify the three completed cold runs and retain the exact measurements used when promoting
Sa(10)=192. Only run9 is a proof source. Run3 and run8 predate the implicit-contraction fix and are
retained solely to compare performance. All three independently reached UNSOLVABLE.

Run8 is 13.874% faster than run3. Run9 is 12.456% faster than run3 and 1.646% slower than
run8 (6791.7 CPU seconds). Run9's proof-safety fix therefore carried no material memory cost and a
small matched-time cost. Run3 lacks complete embedded provenance; its numbers remain diagnostic.

Validation and disposition
--------------------------

- `tools/check_provenance.py` passes run8 and run9.
- `tools/extract_evidence.py audit run9_out_sa193.txt` reports 857 interpreted lines, 848 distinct
  comparable states and zero contradictions.
- Run9 was cold (`cache=(none, cold)`), completed all sixteen roots in one session, passed the
  positive Sa(192) control, and emitted zero `rb-suppressed` markers.
- Exit code 1 is the driver's expected code for a definitive UNSOLVABLE result; it is not an abort.
- The separate k=8 Pareto-prefix census on the instance is not part of these measurements and was
  left running.
